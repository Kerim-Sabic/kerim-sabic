### Start here: Lightning P2P

**Send files between devices without a cloud upload or an account.**

[Lightning P2P](https://github.com/Kerim-Sabic/lightning-p2p) is my open-source file-sharing and chat project, built with Rust, Tauri, and iroh. Transfers use encrypted QUIC connections and BLAKE3 integrity checks, with relay fallback when a direct connection isn't available.
